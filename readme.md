# Żabka3 – Scraper + Max Punkty + Frontend Graffiti

Projekt zbiera dane z:
- Żabka.pl
- Jush.pl
- Gazetki Żabki

Następnie:
- scala je w products.json
- liczy punkty
- liczy maksymalne punkty dla budżetów 10/20/30/40/50/100 zł
- filtruje po kategoriach
- wyświetla wyniki w frontendzie graffiti + neon + pixel-art

## Instalacja
npm install

## Scraper
npm run scrape

## Frontend
Wrzucić folder frontend/ na GitHub Pages
